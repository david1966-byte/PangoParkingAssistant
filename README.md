# עוזר חניה לפנגו – פרויקט Android Studio

אפליקציה שמזהה מתי הרכב מתחיל/מסיים נסיעה (על בסיס חיישני התנועה של הטלפון,
לא GPS מתמשך שמרוקן סוללה), ומתריעה לך לסיים חניה בפנגו + עוזרת למצוא היכן חנית.

## ⚠️ חשוב לדעת לפני שמתחילים
לאף אפליקציית חניה בישראל (פנגו, פנגו פארק, סלופארק וכו') **אין API ציבורי**
שמאפשר לאפליקציה חיצונית לסיים או להתחיל חניה בשמך. לכן האפליקציה הזו:
- **לא** מסיימת את החניה עבורך אוטומטית.
- **כן** מזהה שהתחלת לנסוע ומציגה התראה עם כפתור שפותח את פנגו בשבילך,
  כדי שתלחץ "סיום חניה" בעצמך תוך שנייה.

## איך זה עובד
1. **Activity Recognition API** של גוגל מזהה מעברים בין "עומד/הולך" ל"ברכב" -
   ללא GPS פעיל תמידית, חוסך סוללה.
2. כשמזוהה **יציאה** ממצב נסיעה (=החניה) → נשמר המיקום הנוכחי כ"מקום החניה".
3. כשמזוהה **כניסה** למצב נסיעה (=יצאת לדרך) → מוצגת התראה שמזכירה לסיים
   חניה בפנגו, עם כפתור שפותח את האפליקציה ישירות.
4. כפתור "מצא את החניה שלי" פותח ניווט הליכה ב-Google Maps למיקום השמור.

## לפני שבונים – שני דברים לבדוק/להתאים

### 1. שם החבילה (package name) של פנגו
בקובץ `PangoLauncher.kt` יש רשימת שמות חבילה נפוצים לפנגו. **מומלץ לוודא** מהו
השם המדויק במכשיר שלך:
- הגדרות מכשיר → אפליקציות → פנגו → פרטים מתקדמים, או
- דרך `adb shell pm list packages | grep -i pango` כשפנגו מותקנת במכשיר מחובר.

עדכן את הרשימה ב-`KNOWN_PANGO_PACKAGES` בהתאם אם צריך.

### 2. אופטימיזציית סוללה
כדי שהמעקב ברקע יעבוד באופן אמין (במיוחד באפליקציה סגורה), מומלץ להוסיף למשתמש
בקשה לפטור מאופטימיזציית סוללה (Battery Optimization) עבור האפליקציה. זה לא חובה
להרצה ראשונית אבל משפר מאוד את האמינות בטלפונים עם ניהול סוללה אגרסיבי
(שיאומי, וואווי, סמסונג וכו').

## איך בונים

### אפשרות א' – Android Studio (הכי מלא, כולל דיבאגר)
1. פתח את התיקייה `PangoParkingAssistant` ב-Android Studio (גרסה עדכנית, Hedgehog ומעלה).
2. תן ל-Android Studio לבצע Gradle Sync (הוא ישלים אוטומטית את ה-Gradle Wrapper
   אם חסר).
3. חבר מכשיר Android אמיתי (מומלץ מאוד - זיהוי תנועה לא עובד טוב באמולטור)
   או צור אמולטור עם חיישני תנועה מדומים.
4. הרץ (Run) על המכשיר.
5. באפליקציה: לחץ "הפעל מעקב נסיעה/חניה", אשר את כל ההרשאות המבוקשות
   (מיקום, זיהוי פעילות, התראות, ומיקום ברקע).

### אפשרות ב' – בנייה בענן עם GitHub Actions (ללא שום התקנה במחשב)
בפרויקט כבר קיים קובץ `.github/workflows/build.yml` שמגדיר בנייה אוטומטית.
כל מה שצריך לעשות:
1. לפתוח חשבון GitHub חינמי (github.com).
2. ליצור repository חדש ולהעלות אליו את כל תוכן התיקייה `PangoParkingAssistant`
   (כולל התיקייה `.github` הנסתרת - חשוב לוודא שהיא עולה).
3. להיכנס ללשונית "Actions" בריפוזיטורי - הבנייה תתחיל אוטומטית תוך שניות.
4. אחרי שהריצה מסתיימת בהצלחה (סימן ✔ ירוק), לגלול למטה ל-"Artifacts"
   ולהוריד את הקובץ `pango-parking-assistant-debug-apk` - זהו ה-APK המוכן.
5. להעביר את קובץ ה-APK לטלפון ולהתקין (יידרש אישור "התקנה ממקור לא מוכר").

### אפשרות ג' – שורת פקודה במחשב אישי (JDK 17 + Android SDK Command-Line Tools)
```bash
cd PangoParkingAssistant
./gradlew assembleDebug
```
ה-APK ייווצר בנתיב `app/build/outputs/apk/debug/app-debug.apk`.
(דורש התקנת JDK 17 ו-Android SDK Command-Line Tools מראש, וכן להריץ פעם אחת
`gradle wrapper` כדי ליצור את קובצי ה-wrapper החסרים בפרויקט הזה.)

## מבנה הפרויקט
```
app/src/main/java/com/parkassist/pango/
├── MainActivity.kt              # מסך ראשי, טיפול בהרשאות
├── ParkingMonitorService.kt     # שירות קדמה שנרשם למעברי פעילות
├── ActivityTransitionReceiver.kt# מגיב לאירועי תחילת/סיום נסיעה
├── PangoActionReceiver.kt       # מטפל בלחיצה על "פתח את פנגו" בהתראה
├── PangoLauncher.kt             # פותח את אפליקציית פנגו / חנות Play
├── NotificationHelper.kt        # בניית התראות וערוצי התראה
├── ParkingRepository.kt         # שמירת מיקום חניה + מצב מעקב (SharedPreferences)
└── BootReceiver.kt              # מפעיל מחדש מעקב אחרי ריסטארט למכשיר
```

## הרחבות אפשריות להמשך
- מסך עם מפה מוטמעת (Google Maps SDK) שמציג את החניה ישירות באפליקציה,
  במקום לפתוח את Google Maps החיצוני.
- טיימר חניה עם תזכורת "עוד X דקות נגמר החניה" אם פנגו תומכת בכך בעתיד.
- תמיכה גם באפליקציות חניה נוספות (סלופארק, פנגו פארק) - אותה לוגיקה בדיוק,
  רק צריך להוסיף את שם החבילה שלהן ב-`PangoLauncher`.
